Aetherworld needs a local server

Opening index.html directly won't work — browsers block the game's JavaScript modules on file:// links.

Run one of these in this folder, then open the URL it prints:

npx --yes serve .
python -m http.server 8080

Then visit http://localhost:3000 or http://localhost:8080
